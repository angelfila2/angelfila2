## 🚀 Featured Project

### [SupportFlow — AI Support Ticket Triage](https://github.com/angelfila2/support-triage)

A local AI application that helps classify support tickets, assess urgency,
retrieve relevant FAQ documents, and recommend a reply or human escalation.

**What it includes:**

- Email upload and a React dashboard for reviewing tickets.
- A FastAPI backend with validated ticket and review inputs.
- Local inference through Ollama, with LangChain and ChromaDB for retrieval.
- Deterministic escalation for tickets classified as SEV1 or SEV2.
- SQLite storage using Python's built-in `sqlite3` module.
- Human classification feedback and response-status updates.
- Automated tests for validation, routing, model-output handling, and storage.

**What I'm learning from it:**

How to turn an AI prototype into a more dependable application through clear
validation rules, safe database transactions, organized modules, and regression tests.

**Next areas of improvement:** retrieval relevance, recoverable model failures,
and reproducible evaluation.

### Currently Building: SupportFlow

My current focus is making an AI application more dependable through:

- **Input validation:** enforce ticket constraints and valid human-review categories.
- **Safe persistence:** SQLite transactions, atomic historical imports, and explicit connection handling.
- **Policy controls:** always escalate tickets classified as SEV1 or SEV2.
- **Regression tests:** check routing, malformed model outputs, storage, and validation boundaries.

Next, I'm working toward recoverable inference failures, better retrieval relevance,
and reproducible evaluation. Responses are generated as suggestions for review;
the application does not send customer emails.
